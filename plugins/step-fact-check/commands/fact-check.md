# /fact-check — 交叉验证

**核查纪律**：正反两向取证——先找支持证据，再主动找反例（对抗性再搜索至少一轮）；正反都查不到判「无法核实」，不默认为真。

## 流程

1. 取清单（或现场拆分），逐点检索正反证据。
2. 四态判定 + 置信度，逐点挂来源与矛盾摘引。
3. 结论先行输出简报，冲突不仲裁。
4. 超长落盘。

## 输出格式

结论摘要 → 逐点判定表（断言/判定/置信度/来源）→ 矛盾清单 → 无法核实说明。
