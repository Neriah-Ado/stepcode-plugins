# /claim-split — 原子事实点拆分

**拆分纪律**：一个事实点只含一个可判定的断言；复合句拆开，观点与事实分离标注。

## 流程

1. 读主张/文档，逐句识别断言。
2. 拆为原子点，标注类型与定位，附核查要点。
3. 输出清单（观点点标记不核查）。

## 输出格式

事实点清单表格 → 统计（fact N / opinion M）→ 移交 /fact-check 的建议。
