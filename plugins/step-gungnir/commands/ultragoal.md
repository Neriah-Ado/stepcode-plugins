# /ultragoal — 目标锁定

**完成红线**：动工前先锁判据——没有证据支撑，「完成」二字不出口。判据清单必须经用户确认后才生效。

## 流程

1. 解析目标，产出判据清单（每条含验证方法）。
2. 展示清单与 goal.json diff → 用户确认 → 写盘生效。
3. 推进中逐条对据；宣进不宣成，直到全绿。
4. 全部 satisfied 时输出完成报告（逐条证据）。

## 输出格式

判据清单（判据/验证方法/状态）→ 待确认提示 → 进度/完成报告（附逐条证据）。
