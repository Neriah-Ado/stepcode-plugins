# /mem-search — 记忆检索与复习

**证据门**：每条命中必须标注证据充分性——充分（有出处指针且语义直接支撑）/ 不足（仅相似或出处缺失）；证据不足时明说，禁止据此下结论。

## 流程

1. 读 entries.jsonl（不存在则给沉淀指引，不报错）。
2. 混合检索排序，逐条解析 evidence 指针取原文摘引。
3. 应用证据门标注；到期复习条目置顶并更新 SM-2 元数据（写回需 diff 确认）。
4. 输出命中清单与未命中说明。

## 输出格式

命中清单（摘要 + 充分性 + 指针）→ 到期复习提示 → 零命中/建议说明。
