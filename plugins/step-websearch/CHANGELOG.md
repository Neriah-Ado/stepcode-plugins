# Changelog — step-websearch

遵循 [Keep a Changelog](https://keepachangelog.com/zh-CN/1.1.0/) 风格，版本号遵循 semver。

## [1.0.0] - 2026-11-09

### 新增

- `/websearch` 多引擎并发聚合：零 key 引擎开箱即用、key 后端环境变量自动激活、URL 去重、失败显式标注（移植自 dsh-websearch）
- `/search-brief` 搜索结果归纳：结论先行、矛盾标注、逐句带来源链接
- 结果截断与只取摘要的 Token 经济约定（C5）

## [1.1.0] - 2026-11-10

### 新增

- 引擎健康遥测行：每引擎成功/失败/条数，可用性可观测

## [1.2.0] - 2026-11-10

### 新增

- 全部引擎失效时判「检索不可用」并归因声明，不静默出空结果（G4）

## [1.3.0] - 2026-11-10

### 变更

- 单引擎条数上限 10、超时预算总上限 30s，整体耗时与输出有界

## [1.4.0] - 2026-11-10

### 安全

- `SEARXNG_BASE_URL` 仅接受 http/https；query 长度上限 500 字符

## [1.5.0] - 2026-11-10

### 新增

- `/cron` 周期简报接入与退出码约定（0 正常 / 1 有结果 / 2 检索不可用）
