# /roundtable — 多专家圆桌

**圆桌纪律**：每位专家**先独立、后汇聚**——首轮意见互不可见（防锚定）；汇聚后只呈现共识与分歧，**分歧交用户拍板**，插件不得自动合并结论。

## 流程

1. 读角色模板（或用默认角色），向用户确认专家团构成。
2. 第一轮：逐位独立评审，互不引用。
3. 第二轮：汇聚，产出共识与分歧清单。
4. 分歧逐条交用户拍板；拍板结果可 /mem-save 沉淀。

## 输出格式

专家团构成 → 各专家首轮意见 → 共识清单 → 分歧清单（待拍板）→ 形态声明。
